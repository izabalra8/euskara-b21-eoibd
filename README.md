# Euskara B2.1 — EOI Barcelona-Drassanes 🇪🇺

**Offline study app** in a single HTML file for the Basque B2.1 course (EOI Barcelona-Drassanes, teacher: Eñaut Arretxe).

## Usage

Download `euskara-b21-eoibd.html` and open it in any browser. No internet, installation or account needed — progress is saved in the browser itself (localStorage).

It can also be used online by enabling GitHub Pages (Settings → Pages → Branch: main).

## Features

- **Hiztegia**: full vocabulary per unit, with learned / favorite / hard marking ⭐🔴✓
- **Flashcards with spaced repetition (SRS)**: cards gradually lighten as you master them (dark = still learning, light grey = mastered)
- **Gramatika**: grammar tables and explanations for each unit, with translated examples
- **Idazlana eta ahozkoa**: writing/speaking formulas and real B2.1-level model texts
- **Ariketak**: gap-fill, multiple-choice and translation (flip) exercises grouped by topic, with the course's real answers
- **Azterketak**: per-unit exam (50% vocabulary / 50% grammar) and a global exam across all units, with history and chart
- **Mnemotekniak**: mnemonic rules for hard words
- **Nire maila**: progress dashboard with level distribution and most-failed words
